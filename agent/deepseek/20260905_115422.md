## 一、这个项目最终长什么样

一套**本地运行的个人微信 AI 机器人**，采用"Java 思考 + Python 收发"的桥接架构，
彻底绕开网页版微信协议（会被踢下线 / ret=1203）：

```text
微信(4.x) ──wxauto──▶ Python 桥接脚本 ──POST /api/reply──▶ Spring Boot(Java)
                                                              │  Agent 化调用远端大模型
Web 面板(Vue3, 5173) ──────────────同样走 /api/reply────────▶ 智谱 GLM-4.7-Flash（免费）
                                                              │ DeepSeek deepseek-chat（付费）
                                                              ▼
                                                    MySQL：chat_memory / message_log /
                                                           conversation_setting
                                                    Obsidian 笔记库（关键词 RAG）
```

**一句话**：微信/网页发消息 → Java 用大模型（可免费可付费，可查你本地 Obsidian
笔记）思考 → 回消息；所有对话有记忆、有流水、可管理。

## 二、走过的关键历程（时间线）

1. **初版尝试（网页版 wechat-api）**：按最初需求生成 Spring Boot 3 + Spring AI +
   wechat-api 项目，登录后立刻被"你在其他地方登录 WEB 版微信"踢下线；
   换 wechat-api-uouo 补丁后仍被 `ret=1203` 拒绝——**网页版方案整体废弃**。
2. **转向 wxauto（Windows 微信 UI 自动化）**：先后尝试 wxauto3.9 / wxauto4，
   处理了微信 4.1 版本兼容、消息读取卡死、只读会话列表预览等坑，最终以
   `wechat_bridge_4x_free.py` 轮询方案跑通收发。
3. **Java 端逐步成型**：
   - 多轮记忆：`MessageWindowChatMemory`（每会话 20 条）+ "清空记忆"命令；
   - Obsidian RAG：关键词检索（中文二元组 BM25），22 个文件切 75 块，可命中笔记回答；
   - 角色控制：`rag_friends` 白名单（谁能触发知识库）；
   - Agent 化改造：function calling（查时间 / 搜笔记），模型自主决定是否调工具。
4. **MySQL 持久化**：对话记忆（chat_memory）+ 全量消息流水（message_log）落库，
   重启不丢；场景/方向/IP 多维度区分；会话列表/历史/删除接口。
5. **前后端拆仓库**：`web/` 前端独立成 `ALDOcoder/wechat-ai-bot-web`（Vue3 + Vite
   多会话聊天面板），后端留在 `Spring-AI`。
6. **模型多平台折腾**：DeepSeek 官方 → 硅基流动（404 / 余额不足）→ 智谱
   GLM-4.7-Flash（免费，定为主力），最终**双模型切换**：免费智谱日常 + 付费
   DeepSeek 备用，前端可切、会话级授权、响应标注实际模型。

## 七、风险与教训（写给未来的自己）

- ⚠️ **微信自动化违规**：个人微信协议/UI 自动化违反用户协议，有封号风险，
  务必只用测试小号，控制频率。
- ⚠️ **key 别进 git**：本项目两次把真实 key 写进 application.yml 的兜底值，
  均已用 amend 修复。现在 key 只存在于本地环境变量和 gitignore 的 workspace.xml。
- ⚠️ **付费模型防滥用**：DeepSeek 授权默认全禁（conversation_setting 默认 0），
  服务端强制回落，不信任前端参数。
- ⚠️ **base-url 路径坑**：Spring AI 会自动追加 `/v1/chat/completions`，
  不同服务商路径不同（智谱要覆盖成 `/chat/completions`），改服务商先查路径。
- 📌 **本地服务无鉴权**：只监听本机，不要暴露公网。
